# TikTok AI-Twin Content Pipeline — Build Brief (v2)

> **Changes from v1:** voice is generated by ElevenLabs and lip-synced by the first-party Mirage API (fal kept as fallback); Tesseract is driven from a fixed template with the Mirage Captions API as a degraded fallback; production is decoupled from delivery via a buffer; fixed disclosures moved into the template; TikTok, orchestration, and budget details tightened. The learning loop is unchanged from v1.

## Goal

Build a fully automated daily pipeline for a small-business persona (lawyer or real estate agent) on TikTok:

1. An LLM writes a short script for the day, grounded in a topic backlog I control.
2. **ElevenLabs** speaks the script in my cloned voice.
3. **Mirage Avatar X** (via `api.mirage.app`) lip-syncs my face from a reference clip to that audio.
4. **Mirage Tesseract** edits the raw clip into a finished TikTok: hook text, captions, motion graphics, music, fixed disclosures, and a cover.
5. Finished videos sit in a small buffer; each day one is uploaded to my TikTok **inbox as a draft**, and I get a notification. I review it and tap Publish in the app.
6. Video stats flow back in and drive future script and edit choices (learning loop, unchanged from v1).

The only manual step is reviewing the draft and tapping Publish.

**Constraint:** video generation and editing use Mirage only (Avatar X, Tesseract, Mirage Captions API). Voice synthesis uses ElevenLabs (explicit exception). No Tavus, HeyGen, etc.

---

## Architecture

Two scheduled jobs sharing one DB and one bucket.

```
PRODUCTION job (runs whenever buffer < BUFFER_TARGET, e.g. 2–3)
   ├─ 1. pick_topic        → next item from topic backlog (+ arms, see learning loop)
   ├─ 2. write_script      → LLM: script, hook, caption, hashtags (≤ ~55 s spoken)
   ├─ 3. compliance_script → LLM pass on script text; fail closed
   ├─ 4. tts               → ElevenLabs → voice.mp3 (+ character timestamps)
   ├─ 5. qa_audio          → transcribe vs script, duration ≤ 60 s, loudness; retry TTS (cheap)
   ├─ 6. render_avatar     → Mirage POST /v1/videos (audio + video reference) → raw 720p mp4
   ├─ 7. qa_video          → duration matches audio, black/frozen frames, sampled-frame vision check
   ├─ 8. edit              → Tesseract template render → final 1080×1920 mp4 + cover PNG
   │                          (fallback: Mirage Captions API → captions-only mp4)
   ├─ 9. compliance_final  → check ALL viewer-facing text (overlay, caption, hashtags)
   └─10. enqueue           → status=READY in buffer

DELIVERY job (daily, ~6am PT)
   ├─ 1. dequeue           → oldest READY (skip expired time-sensitive items)
   ├─ 2. upload_draft      → TikTok Content Posting API, inbox (FILE_UPLOAD, chunked)
   ├─ 3. notify            → caption/hashtags, cover PNG, checklist, Re-edit / Regenerate
   └─ 4. heartbeat         → dead-man's switch ping; alert if buffer low or deadline missed
```

## Components

### 1. Topic backlog + script writer (LLM)

- **Topic backlog** (sheet or DB table) I maintain: topic, 3–5 bullet points of what to actually say, `evergreen | timely`, optional `expires_on`. The LLM turns my notes into a script; it does not invent substance.
- Timely topics (market updates, new laws) must include source facts in the prompt (e.g. pulled local market stats, linked articles). The script may only use supplied facts. No sources → fall back to an evergreen topic.
- Output (JSON): `script`, `hook_line`, `caption`, `hashtags`, `est_seconds`.
- Validate before spending money: estimated speech ≤ 55 s (≈ 14–16 chars/s), so the TTS output fits Mirage's 60 s per-request limit.

### 2. Voice: ElevenLabs

- One-time: create a voice clone of me. Prefer **Professional Voice Clone** (best likeness; needs more audio and a verification step). Instant Voice Clone is acceptable for the spike.
- Per run: `POST /v1/text-to-speech/{voice_id}/with-timestamps` → MP3 + character-level alignment.
  - The alignment can drive caption timing in Tesseract, avoiding a separate transcription for captions.
- Maintain a **pronunciation dictionary** (local street names, legal terms, acronyms) and attach it to every request.
- Fix voice settings (stability, similarity, style, speed) in config so delivery is consistent day to day.
- **Verify** current model ID, output format options, and pricing in ElevenLabs docs.

### 3. Audio QA

- Transcribe `voice.mp3`, compare to script (word error rate threshold). Check duration ≤ 60 s and integrated loudness.
- On mismatch: re-generate TTS (up to N times; cents each). Only proceed to the paid video render with approved audio.

### 4. Avatar rendering: Mirage API (primary)

- `POST https://api.mirage.app/v1/videos` (multipart), header `x-api-key: $MIRAGE_API_KEY`
  - `model=mirage-avatar-x`
  - `audio_reference=@voice.mp3` (1–60 s; this IS the performance — the avatar lip-syncs it)
  - `video_reference=@reference.mp4` (my 9:16 talking-to-camera clip)
- Poll `GET /v1/videos/{id}` until `COMPLETE | FAILED | CANCELLED`; download via `GET /v1/videos/{id}/content` (follows redirect).
- **Persist the Mirage `video_id` before polling**, so a crash resumes polling instead of paying for a second render.
- Output: 720p MP4 with non-removable provenance metadata. Most renders finish in < 2 min.
- Files are uploaded directly — no public/presigned URLs for my face or voice.
- **Reference library:** 3–5 reference clips (different outfits/settings), rotated, so videos don't look identical every day. Same quiet room / lighting standards for all.
- **Verify with Mirage (beta):** pricing, rate limits, whether an `actor_id` can reference my app-built AI Twin, and whether a script/TTS input is coming.

**Fallback:** fal `mirage-api/avatar-x/text-to-video` (script + voice sample in, video out) behind the same `AvatarRenderer` interface, used only if the Mirage API is down. Same Mirage model; different voice path.

### 5. Video QA

- Duration ≈ audio duration; no black or frozen segments; audio present.
- Sample 5–10 frames → vision-LLM check for face/mouth artifacts.
- One re-render allowed, subject to budget. The human review in TikTok is the final gate.

### 6. Editing: Mirage Tesseract (primary) / Mirage Captions API (fallback)

- **Template, not agent, at runtime.** Build a brand template `.tsrct` once, interactively, with an agent using the Tesseract skills: fonts, colors, hook overlay, caption style, motion-graphic slots, music bed, **fixed disclosure lower-third/end card** (brokerage name + license #, or "Attorney Advertising" etc.), and cover layout.
- Daily: programmatically fill the template (clip path, hook text, caption timings from ElevenLabs alignment, music file, edit params) and call the Tesseract CLI to render 1080×1920 mp4 + cover PNG. No LLM in the render path.
- Pin the Tesseract CLI version + checksum. Keep a golden-render test so a release that changes the project schema fails in CI, not at 6am.
- Keep each day's editable project next to its render.
- **Fallback:** if Tesseract fails, `POST https://api.mirage.app/v1/videos/captions` with a fixed `caption_template_id` on the raw clip (9:16, ≤ 50 MB, ≤ 5 min). Captions only — mark the run `degraded` in the notification.
- **Music:** only royalty-free tracks licensed for commercial use (Business accounts are limited to TikTok's Commercial Music Library; baked-in copyrighted audio risks muting). Alternative: no baked music, add from CML in-app at publish.
- **Verify:** Tesseract license/commercial terms, headless CLI commands, render time and CPU/GPU needs on the target VM, and whether renders preserve Mirage's provenance metadata.

### 7. Compliance

- Two passes: on the script (before spending money) and on **all final viewer-facing text** (overlay, caption, hashtags).
- Fail closed: skip the item, notify me, keep the buffer serving.
- Mandatory disclosures live in the template, not in LLM output.
- Archive every delivered mp4 + caption + posting date in write-once storage (bar/brokerage ad-retention rules).
- The persona bio must not misrepresent professional licensure. Either label the account as a demo, or operate it for a real licensed professional. Disclose AI-generated likeness where state rules require it.

### 8. Buffer

- Keep `BUFFER_TARGET` (2–3) READY videos. Production runs when the buffer is below target.
- Timely items carry `expires_on`; delivery skips expired items.
- If a draft expires unpublished in TikTok (24 h), re-upload the same file instead of re-rendering.

### 9. Posting: TikTok Content Posting API, inbox mode

- `video.upload` scope, **FILE_UPLOAD** (chunked) — avoids media-domain verification needed for pull-from-URL.
- Start **TikTok app review** in week 1 (privacy policy, ToS, demo video; can take weeks). Use a sandbox test user until approved.
- Tokens: access ~24 h, refresh token rotates (~365 days) → store in a writable secret store, not env vars; alert 30 days before refresh-token expiry.
- Inbox drafts carry no caption, no `is_aigc`, and (verify) no custom cover — these go in the notification.
- **Verify:** current endpoint paths and the pending-draft limit (believed ~5 per 24 h).
- Account: a separate TikTok **Business** account for the persona.

### 10. Notification

- Channel: ntfy / Pushover / Slack (configurable).
- Contents: preview link, one-tap copy of caption + hashtags, cover PNG, checklist (toggle AI label, music, publish within 24 h), `degraded` flag if the captions fallback was used.
- Actions: **Re-edit** (Tesseract only, ~free) and **Regenerate** (new TTS + render).

## Data model (SQLite to start, backed up to the bucket nightly)

- `topics`: id, title, notes, kind (evergreen/timely), sources, expires_on, used_at
- `runs`: id, topic_id, step, status (PENDING/READY/DELIVERED/FAILED/EXPIRED), degraded, arms (JSON), script, hook, caption, hashtags, tts_request_id, voice_path, mirage_video_id, raw_clip_path, tesseract_project_path, final_path, cover_path, cost_tts, cost_avatar, error
- `deliveries`: run_id, delivered_at, tiktok_publish_id, attempt
- `videos`, `snapshots`, `bandit_state`: as in v1

## Config / secrets

`ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID`, `ELEVENLABS_PRONUNCIATION_DICT_ID`, `MIRAGE_API_KEY`, `MIRAGE_CAPTION_TEMPLATE_ID`, `FAL_KEY` (fallback), `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET`, TikTok refresh token (writable secret store), `LLM_API_KEY`, bucket credentials, `NOTIFY_WEBHOOK_URL`, `HEARTBEAT_URL`, `DAILY_BUDGET_USD`, `MONTHLY_BUDGET_USD`, `BUFFER_TARGET`, `DELIVERY_DEADLINE`, `PERSONA`.

## Hosting / orchestration

- Small Linux x86_64 VM (size from the Tesseract spike) running both jobs on cron.
- Each step is idempotent: checks for its artifact, otherwise runs; `runs.step` records progress; external job IDs (ElevenLabs request, Mirage `video_id`, TikTok `publish_id`) are saved before waiting.
- **Budget guard before every paid call:** estimate cost (seconds × rate), reserve against daily and monthly caps including possible retries, then call. Record actual cost after.
- Retries with backoff; alert on failure; **heartbeat** (healthchecks.io-style) so a cron that never ran also alerts; alert if delivery misses `DELIVERY_DEADLINE` or buffer < 1.

## Build order / milestones

1. **Lead-time items:** submit TikTok app review; confirm Tesseract license; ask Mirage about pricing, rate limits, `actor_id`.
2. **Voice spike:** record reference audio → ElevenLabs clone → generate 5 test scripts incl. hard words; build the pronunciation dictionary.
3. **Avatar spike:** record reference clips → Mirage `/v1/videos` with the ElevenLabs audio → judge likeness and lip-sync.
4. **Tesseract spike:** confirm headless CLI, build the brand template, render the spike clip; measure render time. Also test the Captions API fallback.
5. **TikTok inbox upload** of the spike video with a sandbox user.
6. **Production job end to end** in dry-run mode (everything except upload), with QA, compliance, budget guard.
7. **Buffer + delivery job + notification + heartbeat.**
8. Learning loop milestones (v1).

## Acceptance criteria

- Delivery job puts a captioned, branded draft in my TikTok inbox by `DELIVERY_DEADLINE` on ≥ 95% of days, with no manual steps.
- No draft is ever uploaded that failed QA or compliance.
- Every run is logged with costs, artifacts, and external job IDs; a crash at any step resumes without double-paying.
- Daily and monthly spend never exceed their caps.
- Every delivered video and caption is archived for ad-retention purposes.
